# GRIOT V2.0 — App Store listing

Paste each section into App Store Connect → GRIOT → the new 2.0.0 version.
Character limits are Apple's; counts are given where they matter.

Rule followed throughout (Guideline 2.3.1): only describe what's in this build.
No pronunciation/tone *scoring* (deferred), no Igbo/Hausa *lessons* (the
translator supports them; lessons are Yorùbá only), no fixed prices or trial
lengths (they come from the App Store and can change).

Recommended:

```
Learn Yoruba & Translate
```

(24 characters.) Alternatives: `Yoruba lessons & translator` (27), `Speak your family's language` (28).

risks a 2.3.1 rejection. Use it once Igbo lessons ship.

```

GRIOT helps you learn Yorùbá through short, audio-first lessons made for the diaspora — and translate between 14 languages, with unlimited free translations.

LEARN YORÙBÁ
• Your first three phrases in about two minutes

BUILD THE HABIT
• Daily goal, streaks with streak freezes, and XP
```
